# Vrinda Store Sales Analysis – Excel Dashboard

## Project Overview
This project is an Excel-based sales analysis dashboard created for Vrinda Store.
The main goal of this project is to analyze sales performance and customer behavior
using Excel and present the insights in a clear and interactive dashboard.

The dashboard helps in understanding sales trends, customer demographics,
top-performing states, sales channels, and order status.

---

## Objective of the Project
The objectives of this project are:
- To analyze monthly sales and order trends
- To understand customer behavior based on age and gender
- To identify top-performing states
- To analyze sales contribution from different online channels
- To track order status such as delivered, returned, cancelled, and refunded
- To generate business insights for decision-making

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning Techniques

---

## Dashboard Features
- Monthly Sales vs Orders analysis
- Sales distribution between Men and Women
- Orders analysis by sales channels (Amazon, Flipkart, Myntra, etc.)
- Top 5 states by sales
- Age group vs Gender analysis
- Order status analysis (Delivered, Returned, Cancelled, Refunded)
- Interactive slicers for Month, Category, and Channel

---

## Key Business Insights
- Female customers contribute the highest percentage of total sales.
- Sales peak during the early months of the year, showing seasonal demand.
- Amazon is the top-performing sales channel, followed by Myntra and Flipkart.
- Maharashtra and Karnataka are the highest revenue-generating states.
- The majority of orders are successfully delivered, showing strong operational performance.
- Adult age group customers generate the highest number of orders.

---

## Business Recommendations
- Focus marketing campaigns on female customers as they contribute the most revenue.
- Increase inventory and promotions during peak sales months.
- Strengthen partnerships with high-performing sales channels.
- Run targeted campaigns in top-performing states to maximize revenue.
- Maintain delivery efficiency to reduce returns and cancellations.

---

## How to Use the Dashboard
1. Download the Excel file from this repository.
2. Open the file using Microsoft Excel.
3. Use slicers to filter data by month, category, or channel.
4. Analyze the dashboard visuals to understand sales performance and insights.
